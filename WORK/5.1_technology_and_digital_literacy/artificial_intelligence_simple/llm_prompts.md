# Промпты для генерации статей

## Базовый промпт

```text
Напиши статью для детской энциклопедии KidBook о понятии "{concept_name}".
Объясни материал для десятилетнего ребенка простыми словами, но без фактических ошибок.
Используй короткое введение, 3-5 смысловых разделов, понятный пример из жизни,
небольшой чек-лист или вопросы для самопроверки и краткий вывод.
Учитывай описание понятия: {description}
Упомяни связанные понятия: {related_concepts}
Оформи результат в GitHub Flavored Markdown.
```

## Промпт для редакторской проверки

```text
Проверь статью для детской энциклопедии. Найди сложные формулировки,
неподтвержденные обещания и места, которые ребенок может понять неправильно.
Предложи точечные исправления. Не добавляй выдуманные факты.
```
